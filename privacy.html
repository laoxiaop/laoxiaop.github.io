Privacy Policy

Private Client Application · Last updated: 2026-11-07

1. Scope

This policy applies to a private, single-user application operated by one individual for their own personal use. The application is not a public service, has no other users, and does not accept registrations.

2. Data accessed

The application accesses only those data types that the user explicitly authorizes on the third-party service's OAuth consent screen. The exact set of permissions in effect is displayed on that consent screen at the moment of authorization, and the user may decline or revoke them at any time. No data is accessed outside those authorized permissions.

3. Storage

  • All retrieved data is stored locally on the user's own device.
  • The application has no cloud backend and does not upload data to any server.
  • Authorization credentials are kept in the operating system's credential manager, never in plaintext files.
  • No data is synchronized to third-party storage or cloud drives.

4. Sharing

The application does not sell, rent, share, transfer, or disclose any data to third parties, and does not use it for advertising, profiling, credit assessment, or any commercial purpose. No third-party analytics, tracking, or advertising SDKs are used.

5. Retention and deletion

  • Data is retained locally at the user's discretion until the user deletes it.
  • Deleting the local data store permanently removes all data.
  • The user may revoke the application's access at any time from the third-party service's account permissions page, after which the application immediately loses access.

6. Security

The application runs only on the user's own device. All network communication uses HTTPS. Because data never leaves the device, there is no server-side data exposure.

7. Third-party API terms

Use of third-party APIs complies with the applicable Google API Services User Data Policy, including its Limited Use requirements. Data obtained through those APIs is used solely to provide the functionality requested by the authorizing user, and for no other purpose.

8. Contact

No personal contact details are published on this page.

隐私政策（中文摘要）

  • 存储：所有数据仅保存在使用者本人设备本地，没有云端服务器，不上传。凭据存放于操作系统凭据管理器。
